# QuickUse (Fabric 1.21.4)

Delete — меню. В нём список: предмет (id) + клавиша + своё название.
Нажал клавишу -> предмет берётся в руку (даже из глубины инвентаря), ПКМ, прошлый предмет возвращается,
в локальный чат пишется «Использован: <название>».

Сборка: пуш на GitHub -> Actions -> Artifacts -> quickuse-jar.
Нужен Fabric Loader + Fabric API.
